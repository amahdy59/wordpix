# WordPix Study Page — Developer-Ready Redesign Specification

## 1. Objective

Redesign the existing WordPix Study experience at:

`#/learn/:unitId/study`

with **The Bathroom** as the pilot unit.

The redesign must transform the page from a flat library of study materials into a guided learning environment that helps learners:

1. know what to study next;
2. learn vocabulary in manageable chunks;
3. hear and recognize words;
4. retrieve words from memory;
5. understand them in context;
6. use them in meaningful language;
7. review weak vocabulary;
8. freely browse reference material when needed.

The redesign must improve:

* information architecture;
* mobile and desktop UX;
* visual hierarchy;
* learning progression;
* accessibility;
* cognitive load;
* vocabulary retention;
* responsive behavior;
* learner orientation and progress.

Do **not** turn the Study area into another copy of the existing scored lesson flow.

# 2. Critical implementation constraint

The current `LearningMaterialsScreen` is intentionally outside the scored lesson state machine.

Preserve this architectural boundary.

Do **not**:

* rewrite the existing scored lesson engine;
* change lesson completion logic;
* change existing lesson scoring;
* change routes used by normal lessons;
* modify `COURSE_UNITS` in ways that break current lessons;
* make Study completion equivalent to lesson completion;
* remove existing learning-material data because it is no longer directly visible.

The current source explicitly treats Study as independent self-paced/reference material. 

Instead, introduce a separate lightweight **Study Progress** state.

# 18. Retrieval step

After a vocabulary chunk has been presented, immediately introduce retrieval.

Example:

```text
What is this?

[ image of sink ]

sink
soap
mirror
shower
```

Then later:

```text
[ image ]

Type the word:
[____________]
```

Recognition should precede more difficult recall.

Learning sequence:

```text
See
→ Hear
→ Recognize
→ Recall
→ Use
```

Do not mark a word "comfortable" merely because the learner viewed it.
