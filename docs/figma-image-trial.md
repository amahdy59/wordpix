# Figma image trial — first three counting scenes

Create editable vector illustrations for the following exact usage contexts.
No image-generation service or API spend is needed for these vector scenes.
Use a consistent clean adult-oriented illustration style, a neutral background,
natural object colors, and subtle depth. Avoid written numbers, labels, logos,
watermarks, and answer-highlighting treatments. Every assessed object must be
individually countable. Keep equal visual treatment for all groups.

## Frames

Each scene: 1200 × 675 px, with 48 px clear space around the illustration.
Keep crucial objects within the central 1104 × 579 px. Use reusable components
for folders, trays, cups, and boxes. Keep stable scene IDs in frame names.

1. `numbers-counting-1-usage-scene-1`: office desk with three distinct trays,
   ordered from left to right. Exactly 1 folder on the first tray, 2 on the
   second, and 3 on the third. Place a clipboard directly beside the third
   tray. Offset folders so every full folder remains visibly separate.
2. `numbers-counting-1-usage-scene-2`: café counter with three distinct trays
   holding exactly 4, 5, and 6 cups. Arrange cups in clear rows with generous
   separation. Place a kettle directly beside the 5-cup tray, farther from
   the other two trays. Do not cover any cup with the kettle.
3. `numbers-counting-1-usage-scene-3`: storeroom with three distinct groups
   holding exactly 7, 8, and 9 boxes. Arrange each group on the floor in
   countable rows, without stacks hiding boxes. Put the 9-box group beside
   an open door, clearly farther from the other groups.

## Review and delivery

- Inspect all counts and spatial relationships at full size and mobile size.
- Export one SVG and one PNG per scene with the stable scene ID as filename.
- Show a contact sheet for visual review before integrating any asset.
- Trial is illustrative, not photorealistic; use the review to decide whether
  this style suits WordPix before expanding the batch.
- Preserve existing Cloudflare R2 assets and mappings. Trial exports stay local.
