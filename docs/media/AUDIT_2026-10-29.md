## Review order

1. Inspect confirmed binding mismatches and prepare replacement proposals.
2. Review exact-text candidates against the visible image, precise sentence,
   assessed word and required counts/contrasts. Source manifests can be wrong.
3. Search unreviewed library artwork for the 853 uses without exact-text candidates.
4. Inspect local/unlisted references before classifying them as missing remotely.
5. Approve new artwork only after reuse is ruled out and content requirements are
   reviewed. Keep requests grouped by reusable context, not array position.

See [the maintenance workflow](README.md) for commands, naming and review rules.
The scripts produce CSV and JSON review queues in `output/media-catalog/`.
