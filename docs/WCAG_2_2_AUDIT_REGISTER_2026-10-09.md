# WCAG 2.2 criterion register — 9 October 2026

Source: [W3C WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/). This register covers all 86 active success criteria. Removed criterion 4.1.1 is excluded.

This is an evidence register, not a conformance claim. Partial automated and browser evidence cannot prove full WCAG AAA conformance. No criterion is marked fully passed without full-page, complete-process and relevant assistive-technology evidence.

Current scope: reading redesign, new classroom/office scene imagery, local editorial integration, and existing release regressions. Manual screen-reader testing with NVDA/JAWS/VoiceOver, all relevant media alternatives, authentication/error recovery, every focus/contrast state, and 400% zoom still need direct review. Existing older evidence is identified explicitly.

2.4.12 governs full focus visibility; 2.4.13 governs focus appearance. The project requires both.
